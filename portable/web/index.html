    On the Bot page, enable Message Content Intent, then copy the bot token.

    Keep it private. It stays in memory on this device only, so enter it again after Mavi restarts. The field clears after a save attempt.
  3. 3

    Choose who can reach Mavi

    Invite the bot, then use a private channel and allow only trusted accounts. Everyone who can view that channel can read Mavi’s messages and files.

    How do I copy channel and user IDs?

    In Discord, open User Settings → Advanced and turn on Developer Mode. Right-click your private channel and choose Copy Channel ID. Right-click your own profile and choose Copy User ID.
