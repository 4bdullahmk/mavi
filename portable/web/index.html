SETUP GUIDE

Connect your own Discord bot

  1. In the official Discord Developer Portal, create an application and copy its Application ID into Settings. It is optional, but enables the invite link and checks the token’s bot identity.
  2. Open the app’s Bot page and enable Message Content Intent. Copy the bot token into this device’s Settings when you are ready to connect. It is kept in memory only and must be entered again after Mavi restarts.
  3. Create a private server channel visible only to the bot and people you trust. In Discord, open User Settings → Advanced and enable Developer Mode; then right-click the channel and your own profile to copy their IDs into Settings. See Discord’s guide to copying IDs. Only allowlist accounts you trust.
  4. Use the invite link in Settings to add only the bot to your server. It requests the bot scope with View Channels, Send Messages, Embed Links, Attach Files, and Read Message History permissions. It does not request Administrator.
  5. In Settings, opt in to Discord chat replies. Remote tasks, which can work with files on this device, have a separate checkbox and remain off by default.
  6. Save the settings and wait for the status above to say Connected. Then test in the selected channel with !mavi ask Hello.

The bot can act only through this Mavi instance while it is running. Never share its token. Do not enable remote tasks unless you trust every allowlisted account with the local actions described in Settings.

COMMAND GUIDE

Work with Mavi from Discord

Ask!mavi ask <request> Ask a local question.
Task!mavi task <request> Start local multi-step work. Requires the separate task opt-in.
Image!mavi image <prompt> Generate an image and receive it in Discord.
Edit!mavi edit <instruction> Attach 1–3 PNG or JPEG images.
Status!mavi status Check your task’s progress.
Steer!mavi steer <instruction> Guide an active chat, browser, or computer task.
Answer!mavi answer <reply> Reply when Mavi is waiting for your input.
Stop!mavi stop Stop your active task.
Help!mavi help Show the available commands.

Your computer must be awake and connected to the internet for Discord tasks to run.
